## Now (Current Sprint / Quarter) — the work primitive

This table is the single home for open work. **A finding with no owner and no due is not tracked work — it is a note that will be re-discovered forever.** Anything the system surfaces that needs a human to act (a `/review` judgment item, a triggered hypothesis, a stalled decision, a diagnosed gap) lands here as an owned row, or it does not count as assigned.

Rules:
- **Every row has an `Owner` and a `Due` — never a silent blank.** If you cannot name an owner, the item is not ready to be Now work — leave it in its source file and say so.
- **`Due` is a date, or the literal `unscheduled`.** Use `unscheduled` for work that is genuinely in flight but not yet timeboxed — e.g. active features captured at setup, before any deadline exists. `unscheduled` is an explicit, visible state, not a missing value; `/weekly-plan` and `/review` surface unscheduled rows to be given a real date. **Never fabricate a date** to fill the field — an invented deadline is worse than an honest `unscheduled`.
- **`Source` links back to the finding** — the hypothesis slug, decision file, `maintenance/log/` entry, or ingestion record that created the row. This is the finding → work audit trail.
- `Status`: `todo` | `in-progress` | `blocked` | `done`. Mark `done` rows for the next `/review` to sweep into **Recently Shipped**.
- Initiative-scale rows can be exported to Linear/Jira with `/create-tickets`.
