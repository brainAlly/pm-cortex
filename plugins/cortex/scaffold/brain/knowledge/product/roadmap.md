## Now (Current Sprint / Quarter) — the work primitive

This table is the single home for open work. **A finding with no owner and no due date is not tracked work — it is a note that will be re-discovered forever.** Anything the system surfaces that needs a human to act (a `/review` judgment item, a triggered hypothesis, a stalled decision, a diagnosed gap) lands here as a row with an owner and a date, or it does not count as assigned.

Rules:
- **Every row has an `Owner` and a `Due`.** No blanks. If you cannot name an owner, the item is not ready to be Now work — leave it in its source file and say so.
- **`Source` links back to the finding** — the hypothesis slug, decision file, `maintenance/log/` entry, or ingestion record that created the row. This is the finding → work audit trail.
- `Status`: `todo` | `in-progress` | `blocked` | `done`. Mark `done` rows for the next `/review` to sweep into **Recently Shipped**.
- Initiative-scale rows can be exported to Linear/Jira with `/create-tickets`.
