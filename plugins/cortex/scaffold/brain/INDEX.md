# Brain Index

Central routing map. Start here for any task that spans multiple areas.

## Quick Routing

| I need to... | Go to |
|---|---|
| Understand the product strategy | `knowledge/strategy.md` |
| Check feature status or roadmap | `knowledge/product/roadmap.md` |
| Find user insights or personas | `knowledge/users/` |
| Look up a competitor | `knowledge/market/competitors/` |
| Check a stakeholder's open asks | `stakeholders/` |
| Review active hypotheses | `hypotheses/INDEX.md` |
| Find a past decision | `decisions/INDEX.md` |
| See recent meeting notes | `ingestion/meetings/` |
| Find a raw interview transcript | `source/interviews/` |
| Check my writing preferences | `style/writing.md` |

## Knowledge Areas

- **Knowledge tier** → `knowledge/INDEX.md` (strategy, product, users, market, org)
- **Strategy** → `knowledge/strategy.md`
- **Product** → `knowledge/product/` (roadmap, metrics, features)
- **Users** → `knowledge/users/` (personas, segments, insights)
- **Market** → `knowledge/market/` (landscape, trends)
- **Org** → `knowledge/org/` (team, rituals, tools)

## Active State

- **Hypotheses** → `hypotheses/INDEX.md`
- **Decisions** → `decisions/INDEX.md`
- **Stakeholders** → `stakeholders/INDEX.md`

## Memory Pipeline

- **Working memory** → `ingestion/` (interviews, meetings, market, adhoc)
- **Immutable source** → `source/` (raw copies, never edited)
- **Long-term memory** → `knowledge/` (promoted patterns, 3+ independent observations)

## Personalization

- `style/writing.md` — output structure, length, tone preferences
- `style/frameworks.md` — preferred analysis and prioritization frameworks
- `style/patterns.md` — recurring thinking patterns and approaches

## Reference (outside brain/)

These directories live at the project root alongside `brain/`. Load on demand — not part of the default context sweep.

| Directory | What it contains | When to load |
|---|---|---|
| `templates/` | Blank starter templates (PRD, OKR, roadmap, retro, interview, launch checklist) | When PM asks to start from a template |
| `docs/examples/` | Real-world PRD examples for reference and style calibration | When drafting a PRD |
| `docs/advanced/` | Advanced workflow guides (parallel agents, context management, plan mode) | When PM asks about advanced system usage |
| `rules/` | PM's process rules (discovery, data, prioritization, shipping, writing) | When running discovery, prioritization, or shipping workflows |
| `maintenance/log/` | Weekly `/review` run logs | When checking maintenance history |
| `outputs/` | Generated artifacts (PRDs, analyses, plans) | When PM asks to reference or continue prior output |
